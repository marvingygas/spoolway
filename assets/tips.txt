# the tips the dispatch tab shows on its last row, one per line. the board
# shuffles them and shows a new one every 30 seconds.
#
# a feature gets a tip when a user cannot see what it does without digging
# deep into the documentation.
# a tip says what a feature does, and never names the key that runs it.
# a tip puts names in quotes, such as "agent:" or "edit pipeline".
#
# a line in brackets starts a section, such as [queue]. the board shows the
# section's name before each of its tips: tip: queue · <the tip>.
# a tip is one lowercase sentence, and that whole row fits 80 columns.

[dispatch]
a held task can "resume" at any step, or skip to "done".
"open task" opens the task file, "open plan" its plan.
"focus" brings a task's pane to the front.
"pause when <step> finishes" lets the step end first.
"restart" reruns a step. an agent gets a fresh session.
"unqueue" moves a task back to pending.
"unqueue" deletes a task's local branch and worktree.
"update config" loads changes into a running dispatcher.
quitting stops dispatching, but running lanes keep going.
a failed issue hook can be skipped, or run again.
the spool by the name turns while a dispatcher runs.
"RECENT" lists the moves tasks made, newest first.
"slots 1/∞" means that agent has no concurrency cap.

[tabs]
dispatching keeps running while you look at other tabs.
a project set up in home mode has no overrides tab.

[queue]
ticking several groups or routines queues them all at once.
the queue and overrides tabs each have a search.
done tasks can be shown or hidden on the queue tab.
writing a task file does not queue it. the queue tab does.
queueing moves a group's tasks from pending into the queue.
tasks you queue while dispatching start right away.
a group is one chain. each task waits for the one before it.
"edit depends on" makes a group wait for another group.
"edit lands in" changes the branch a group's work lands in.
"edit pipeline" moves a pending task to another pipeline.
"gate" pauses one task after a step you pick.
"trial" runs one group on several pipelines to compare them.
"save as routine" keeps a group to queue again later.
a task waits until its dependency is done and archived.
a dependent task starts from its dependency's branch.
if a start branch is gone, set "starts_from:" and resume.
"use /spoolway-tasks" marks a plan not cut into tasks yet.
never delete queue files by hand. "unqueue" the task.

[routines]
"edit schedule" makes a routine run on a timer, as a job.
jobs fire only while dispatching. missed runs are skipped.

[overrides]
overrides set config values for this machine only.
a prompt can be copied and edited for this machine only.

[eval]
the eval tab shows what each lane ran and what it cost.
the eval tab has three tables: "lanes", "dirs" and "trials".
trials can be opened from the eval tab's "trials" table.
the eval tab sorts by any column, either way, and filters.
the eval tab shows totals or per-task figures.
the eval table on screen can be exported to a CSV file.

[pipeline]
the first step in "steps:" is where every task starts.
raise "version:" after a change, to compare runs.
"task_template:" picks the skeleton of a pipeline's tasks.
"agent:" makes a step an agent step, run by that profile.
"prompt:" names a step's prompt file, by default its id.
"model:" is required on every agent step.
"effort:" sets how hard a step's model thinks.
"skills:" opens a step's first prompt with those skills.
"session: true" continues an earlier step's chat.
"slot: false" lets a step run without using an agent slot.
"gate:" on a step makes a person check its outcome first.
"on_pass:" names the step a task goes to on a pass.
"on_fail:" names where a fail goes, else the task blocks.
"loop:" caps how many times a task may arrive at a step.
"run:" makes a command step. its exit code is the outcome.
"timeout:" kills a command after that long. default 30m.
"background: true" moves a task on while its command runs.
"hide: true" runs a command step without a pane.
"first:" runs a step only on the first task of a chain.
"last:" runs a step once per chain, on its top task.
"serial: true" runs a command step for one task at a time.
a task runs every step. skip one with another pipeline.
command steps cannot be gated. gate the next agent step.
a gate still waits for a person in an unattended run.
pipeline edits apply after "update config" or a restart.
prompt edits need no reload. each lane reads it fresh.

[lanes]
a lane is one agent on one step of one task, in its own pane.
each task gets a herdr workspace, named "spoolway/<task>".
finished lanes stay open, and you can still type into them.
a row reading "prompt" waits on a permission question.
interrupting a lane pauses its task. typing to it resumes.
a lane is paused after three reminders with no report.
a paused task frees its slot for other tasks.

[stopping]
stopping tears nothing down. the next run picks lanes up.
"interrupt them now" pauses tasks until the next dispatch.
a gate pause is a finished step waiting for your go-ahead.
the status log in a task file says why the task blocked.
leaving "blocked" resets every step's loop count to zero.
pausing kills a command. resuming runs it from the start.
only you can resume a task. its own lane cannot.

[config]
a quiet lane is asked to report after "dispatch.lane_quiet".
"dispatch.auto_commit" commits work a lane left uncommitted.
"dispatch.priority = group" finishes started groups first.
"dispatch.lane_child_ceiling" ends a lane's stuck program.
"dispatch.visible_lanes" sets how many panes stay open.
"dispatch.hide_commands = true" runs commands with no pane.
"dispatch.autofocus_panes" raises a pane that needs you.
"dispatch.lane_layout = tabs" gives each step its own tab.
"dispatch.tips = false" hides these tips.
"unattended.enabled" hands blocked tasks to an agent.
"unattended.max_output_tokens" caps a run's output tokens.
"unattended.max_cost_usd" caps what a run may spend.
"housekeeping.update_check" tells you about new releases.
"housekeeping.calibrate_window" sets calibration's lookback.
"housekeeping.retention_days" deletes logs past that age.
"housekeeping.archive_retention_days" prunes old done tasks.
"watch.dirs" adds folders whose sessions count toward cost.
"issue_tracking.hook" names the script for your tracker.
"issue_tracking.project_key" names your project: owner/repo.
"issue_tracking.key_in_names" puts issue keys in branches.
"ask_to_deactivate = false" skips the issue question.
an agent's "kind" picks the agent: claude, codex or pi.
an agent's "concurrency" caps its lanes running at once.
"session_reuse_ctx" reuses a chat only below this % full.
"session_blocked_ctx" stops an agent at this % of context.
an agent's "permission_mode" sets the mode it starts in.
a model's "context_window" sets how many tokens it can hold.
"compact_ctx" sets how full a chat gets before it shrinks.
"prompt_cache_ttl" starts a fresh chat after a long pause.
"local = true" marks a model that runs on your machine.

[commands]
most board actions have a command too: "spoolway --help".

[pull requests]
spoolway never merges. merging is your call.
"unqueue" keeps the pushed branch and pull request.
